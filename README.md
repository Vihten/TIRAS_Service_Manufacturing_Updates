# TIRAS Service Manufacturing Updates

Публічний канал готових Windows-збірок **TIRAS Service Manufacturing**.
Вихідний код застосунку зберігається окремо у приватному репозиторії.

## Завантаження

[Останній реліз](https://github.com/Vihten/TIRAS_Service_Manufacturing_Updates/releases/latest)
містить повний портативний ZIP, інструкцію `README-Windows.md`, контрольні суми
`SHA256SUMS.txt` і необов'язковий скрипт стиснення на диску.

Розпакуйте весь ZIP в окрему папку й запустіть `TIRAS_Service_Manufacturing.exe`.
Не переносіть EXE окремо від решти файлів. Потрібні Windows 10/11 x64 та
[Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
Flutter і Python встановлювати не потрібно.

## Режими роботи

У звичайному режимі програма автоматично виявляє сумісні пристрої TIRAS на
ESP32-C3/S3 і запускає оновлення, якщо воно потрібне. Прошивки завантажуються
з GitHub; не від'єднуйте пристрій під час запису.

Для перегляду інтерфейсу без звернення до пристроїв запустіть EXE з `--preview`.
Перед виробничим використанням нової версії проведіть контрольне випробування
на пристроях. Відомі обмеження наведено в описі кожного релізу.

## Розмір

Для версії 1.0.0 ZIP має приблизно 24,30 MiB, розпаковані файли — 39,88 MiB.
Необов'язкове Windows LZX стиснення зменшує зайняте файлами місце на NTFS
приблизно до 23,74 MiB, не змінюючи вміст. ZIP не зберігає цей режим:
стиснення потрібно застосувати після розпакування, як описано в інструкції.

## Сторонні компоненти

Пакет містить оригінальний esptool 5.3.1 із підписом Espressif та його ліцензію.
[Вихідний код esptool](https://github.com/espressif/esptool/tree/v5.3.1).
Ліцензії Flutter/Dart-залежностей також включені до пакета.
